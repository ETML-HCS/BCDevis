BCDevis 7.0.2 - Livrable pour Aleksandra
Clinique Bellecour

NOUVEAUTES 7.0.2

- L'état du devis indique Brouillon, Enregistré ou Modifié selon la version
  réellement présente dans Mes devis.
- Le suivi commercial facultatif regroupe les statuts, les filtres, les notes,
  les prochaines relances, les compteurs et les rappels au démarrage.
- Le menu Catalogue propose les vues Auto, Mobile et Bureau. Le choix est
  mémorisé sur le poste sans modifier l'affichage des autres appareils.
- Sur iPad et smartphone, les actions essentielles sont plus faciles à toucher
  sans modifier l'interface sur ordinateur.
- Dans la caisse tactile, un indice explique le balayage vers la gauche et le
  bouton Annuler restaure immédiatement le dernier soin retiré.
- L'éditeur des tuiles dispose d'un aperçu direct, d'une recherche, de filtres
  et de commandes tactiles plus confortables.
- L'icône d'enregistrement a été redessinée en SVG net à toutes les tailles.
- Le nouvel onglet Réglages > Données peut relier plusieurs postes à la
  base PostgreSQL centrale par une API HTTPS sécurisée.
- Les devis, compteurs et réglages métier sont synchronisés ; les préférences
  d'affichage et le brouillon ouvert restent propres à chaque poste.
- Une coupure réseau n'interrompt pas le travail et les conflits sont résolus
  explicitement après création d'une sauvegarde JSON.
- L'option Numéros uniques centralisés attribue les numéros dans PostgreSQL
  et réserve quelques numéros utilisables en cas de coupure.
- La nouvelle fenêtre Documents PDF importe, recherche et affiche les PDF
  partagés sans quitter BCDevis.
- Cet écran de nouveautés apparaît une seule fois pour la version 7.0.2.

INSTALLATION WINDOWS

Double-cliquer sur BCDevis-7.0.2.exe. L'application est portable et ne
demande pas d'installation.

Au premier lancement, un dossier data est créé à côté de l'EXE. Toujours
conserver et déplacer l'EXE avec ce dossier afin de garder les réglages,
le brouillon et l'historique.

L'EXE n'est pas signé numériquement. Windows peut donc demander une
confirmation au premier lancement.

INSTALLATION LINUX X64

Dans un terminal placé dans le dossier du fichier :

  chmod +x BCDevis-7.0.2-linux-x86_64.AppImage
  ./BCDevis-7.0.2-linux-x86_64.AppImage

Les données sont enregistrées dans le profil local de l'utilisateur.

INSTALLATION CHROMEOS

L'archive BCDevis-7.0.2-chromeos.zip contient la PWA statique à publier
sur un hébergement HTTPS. Elle ne s'installe pas directement depuis le
fichier ZIP.

1. Décompresser l'archive.
2. Publier le contenu du dossier site sur une adresse HTTPS.
3. Ouvrir cette adresse dans Chrome sur le Chromebook.
4. Choisir le menu Chrome > Caster, enregistrer et partager >
   Installer la page en tant qu'application.

Les devis et réglages restent dans le profil Chrome utilisé. Avant de
changer de Chromebook ou de profil, créer une sauvegarde complète JSON.
Sous ChromeOS, le bouton PDF ouvre l'impression : choisir Enregistrer au
format PDF.

CONNEXION A LA BASE CENTRALE (FACULTATIVE)

L'administrateur doit d'abord déployer BCDevis Central et PostgreSQL. Dans
Réglages > Données, activer Connecter ce poste, saisir l'adresse HTTPS de
l'API, le compte et le nom de l'appareil, puis tester le serveur. La ligne
Base de données doit afficher PostgreSQL prêt avant la connexion.

Après la connexion, l'option Numéros uniques centralisés peut être activée et
enregistrée. Les séries sont réservées sans doublon pour tous les postes. Une
petite réserve reste utilisable hors connexion ; des numéros non utilisés
peuvent donc laisser des trous.

Le bouton Documents PDF ouvre la bibliothèque centrale. Il permet d'importer
un PDF de 8 Mo maximum, de le retrouver par devis ou client, de l'afficher et
de le télécharger. Le devis et le client ouverts sont associés à l'import.

Les identifiants PostgreSQL ne sont jamais saisis dans BCDevis : ils restent
sur le serveur. Le mot de passe du compte applicatif n'est pas conservé sur
le poste. La documentation technique du serveur se trouve dans le dossier
central-server du projet source.

ENVOYER

E-mail ouvre directement l'application e-mail avec le PDF déjà joint. À joindre
regroupe WhatsApp et Outlook Web ; BCDevis crée alors le PDF dans Téléchargements
afin de pouvoir l'ajouter manuellement au message.

MODELE DE DEVIS

Dans BCDevis, ouvrir le menu ... en haut du devis, choisir Importer, puis
sélectionner MODELE-DEVIS-V7.json. La date et le prochain
numéro sont attribués automatiquement.

SAUVEGARDE

Avant un changement d'ordinateur, ouvrir Historique puis Sauvegarde
complète. Sur le nouveau poste, utiliser Historique puis Restaurer.

VERIFICATION

Le fichier SHA256SUMS.txt permet de contrôler l'intégrité des trois
applications et des documents. Les détails d'utilisation se trouvent
dans le dossier 4-Documentation.
