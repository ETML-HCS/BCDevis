BCDevis 8.7.1 - Livrable pour Aleksandra
Clinique Bellecour

NOUVEAUTES 8.7.1

Version de production : elle remplace toutes les versions precedentes.

- L'ecran Quoi de neuf ? est redessine pour marquer cette version.
- Le menu ... du devis ne garde que Dupliquer, Exporter, Importer et Vider :
  la langue du PDF se choisit avec le bouton de la caisse ou Ctrl+L.
- Le PDF existe en huit langues : francais, anglais, allemand, italien,
  espagnol, portugais, ukrainien et russe. Le bouton de langue a gauche
  d'Imprimer (ou Ctrl+L) ouvre le choix ; les touches 1 a 8 choisissent
  directement. Les soins et les mentions par defaut sont traduits.
- Devis en euros : Reglages > Tarifs > Paiement en euros. Indiquez le taux
  (ou actualisez-le avec le bouton BCE) et la commission de change (2 a 3 %
  conseilles, pour ne pas perdre d'argent si l'euro baisse avant le change).
  Un choix CHF / EUR apparait dans la caisse ; le PDF et le message d'envoi
  sont alors en euros, avec le taux applique. Le taux est fige dans le devis.
- Mes devis s'ouvre sur A faire : les relances et les factures du jour,
  avec le bouton de l'action attendue sur chaque ligne. Tous les devis est
  un tableau que l'on trie en cliquant sur un titre de colonne.
- WhatsApp : si Ctrl+V ne colle pas le PDF, le bouton Afficher le PDF le
  montre dans l'Explorateur : glissez-le dans la conversation. Cela marche
  aussi avec WhatsApp Business et WhatsApp Web.
- Les petits textes des reglages et de la caisse sont plus grands.
- Le serveur central 8.7.1 est plus rapide et refuse un serveur trop ancien.

DEJA DISPONIBLE (8.6.2 et avant)

- Le choix du tarif est plus compact : sur telephone, les trois choix
  n'affichent plus que leur icone, et seul le tarif actif garde son
  sous-titre. Les libelles restent lus par les lecteurs d'ecran.
- Les icones Nouveau devis, panier vide / onglet Devis et Entreprise sont
  redessinees.
- WhatsApp : le bouton ouvre la conversation du client avec son numero et
  le message. Le PDF est deja copie : faites Ctrl+V dans la conversation,
  puis envoyez (WhatsApp ne permet pas de joindre un fichier tout seul).
- Les zones du corps affichent un repere sur la silhouette et plusieurs
  icones ont ete redessinees pour un style homogene.
- Parametres : Numerotation et dossier des PDF sont dans Devis & suivi.
- Corps interactif plus précis : cliquez sur l'avant-bras, le genou, le bas du
  dos... pour ne voir que les soins de cette zone. Des pastilles sous le
  mannequin offrent le même accès, plus facile au doigt.
- Les zones déjà présentes dans le devis restent colorées sur le mannequin.
- Rabais personnalisé : double-cliquez sur une ligne du devis pour ouvrir la
  modale concise et discrète. Choisissez un rabais en % ou en CHF, ou cliquez
  sur un tag rapide (2 %, 3 %, 5 %, 10 %). Il apparaît sur la ligne, dans le
  total et sur le PDF.
- Avant de restaurer une sauvegarde, BCDevis télécharge un instantané de vos
  données actuelles.
- Le raccourci Ctrl+L ouvre le choix de la langue du PDF en un instant.
- Réglages > Devis et suivi permet toujours de générer le PDF du devis en
  anglais, sans changer l'interface de BCDevis.
- Réglages > Données conserve l'assistant de migration vers
  https://bcd.athys.ch/ : il prépare le transfert sans copier les mots de
  passe ni les sessions.
- Le suivi commercial facultatif regroupe les statuts, les filtres, les
  notes, les prochaines relances, les compteurs et les rappels au démarrage.
- Le menu Catalogue propose les vues Auto, Mobile et Bureau. Le choix est
  mémorisé sur le poste sans modifier l'affichage des autres appareils.
- Le bouton Aide ouvre un centre HTML recherchable, responsive et imprimable,
  disponible hors ligne sans Internet ni PostgreSQL.
- Provisoire : la version web s'ouvre sans connexion tant que le serveur
  central n'est pas en service. Les devis restent sur l'appareil.
- Cet ecran de nouveautes apparait une seule fois pour la version 8.7.1.

INSTALLATION WINDOWS

Double-cliquer sur BCDevis-8.7.1.exe. L'application est portable et ne
demande pas d'installation.

Au premier lancement, un dossier data est créé à côté de l'EXE. Toujours
conserver et déplacer l'EXE avec ce dossier afin de garder les réglages,
le brouillon et l'historique.

L'EXE n'est pas signé numériquement. Windows peut donc demander une
confirmation au premier lancement.

INSTALLATION LINUX X64

Dans un terminal placé dans le dossier du fichier :

  chmod +x BCDevis-8.7.1-linux-x86_64.AppImage
  ./BCDevis-8.7.1-linux-x86_64.AppImage

Les données sont enregistrées dans le profil local de l'utilisateur.

INSTALLATION CHROMEOS

L'archive BCDevis-8.7.1-chromeos.zip contient la PWA statique à publier
sur un hébergement HTTPS. Elle ne s'installe pas directement depuis le
fichier ZIP.

1. Décompresser l'archive.
2. Publier le contenu du dossier site sur une adresse HTTPS.
3. Ouvrir cette adresse dans Chrome sur le Chromebook.
4. Choisir le menu Chrome > Caster, enregistrer et partager >
   Installer la page en tant qu'application.

Les devis et réglages restent dans le profil Chrome utilisé. Avant de
changer de Chromebook ou de profil, créer une sauvegarde complète JSON.
Sous ChromeOS, le bouton PDF ouvre l'impression : choisir Enregistrer au
format PDF.

Dans l'application de bureau, Réglages > Entreprise > Fichiers PDF permet de
choisir le dossier des devis. Téléchargements reste la valeur par défaut. Le
préfixe facture est séparé du préfixe devis, mais le code poste ne change pas :
DEV-20260806A001 correspond à FAC-20260806A001.

CONNEXION A LA BASE CENTRALE (FACULTATIVE)

L'administrateur doit d'abord déployer BCDevis Central et PostgreSQL. Dans
Réglages > Données, activer Connecter ce poste, saisir l'adresse HTTPS de
l'API, le compte et le nom de l'appareil, puis tester le serveur. La ligne
Base de données doit afficher PostgreSQL prêt avant la connexion.

Après la connexion, l'option Numéros uniques centralisés peut être activée et
enregistrée. Les séries sont réservées sans doublon pour tous les postes. Une
petite réserve reste utilisable hors connexion ; des numéros non utilisés
peuvent donc laisser des trous.

Le bouton Documents partagés apparaît après connexion et ouvre la bibliothèque centrale. Il permet d'importer
un PDF de 8 Mo maximum, de le retrouver par devis ou client, de l'afficher et
de le télécharger. Le devis et le client ouverts sont associés à l'import.

Les identifiants PostgreSQL ne sont jamais saisis dans BCDevis : ils restent
sur le serveur. Le mot de passe du compte applicatif n'est pas conservé sur
le poste. La documentation technique du serveur se trouve dans le dossier
central-server du projet source.

ENVOYER

E-mail ouvre directement l'application e-mail avec le PDF déjà joint. À joindre
regroupe WhatsApp et Outlook Web ; BCDevis crée alors le PDF dans le dossier
configuré afin de pouvoir l'ajouter manuellement au message.

MODELE DE DEVIS

Dans BCDevis, ouvrir le menu ... en haut du devis, choisir Importer, puis
sélectionner MODELE-DEVIS-V8.json. La date et le prochain
numéro sont attribués automatiquement.

SAUVEGARDE

Avant un changement d'ordinateur, ouvrir Historique puis Sauvegarde
complète. Sur le nouveau poste, utiliser Historique puis Restaurer.

VERIFICATION

Le fichier SHA256SUMS.txt permet de contrôler l'intégrité des trois
applications et des documents. Les détails d'utilisation se trouvent
dans le dossier 4-Documentation.
