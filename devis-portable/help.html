Premiers repères

Bien démarrer avec BCDevis

Créez, enregistrez, imprimez et téléchargez vos devis en mode local. Connectez la base centrale pour partager les données entre postes et utiliser les bibliothèques Documents et Factures.

Enregistrement

Affiche Non archivé, À enregistrer ou Enregistré. Il ne s’agit pas du statut commercial.

Suivi commercial

Ouvrez Mes devis → Suivi pour gérer les statuts, relances et événements.

Mode local

Les devis, l’aide et les PDF restent utilisables sans Internet ni PostgreSQL.

Statut Envoyé

Enregistrer, imprimer ou télécharger ne change pas le statut commercial. Après E-mail, Outlook Web ou WhatsApp, confirmez le passage à Envoyé.

Devis

Créer et enregistrer un devis

  1. 1
    Choisissez les soins

    Utilisez les familles, la recherche et le tarif Séance ou Pack. Les quantités et remises se règlent dans la caisse.

  2. 2
    Ajoutez le client

    Le nom est recommandé pour retrouver le devis ; l’e-mail est repris lors de la préparation d’un message.

  3. 3
    Enregistrez

    Le bouton Enregistrer archive le devis dans Mes devis. L’indicateur discret affiche Non archivé, À enregistrer ou Enregistré.

  4. 4
    Partagez quand il est prêt

    E-mail, Outlook Web et WhatsApp préparent le PDF et le message. BCDevis propose ensuite de passer le statut à Envoyé.

Ce qui change le suivi

  • La confirmation proposée après une préparation d’envoi.
  • Une action volontaire dans Mes devis → Suivi.
  • L’expiration automatique lorsque la validité est dépassée.

Ce qui ne le change pas

  • Enregistrer le devis.
  • Télécharger son PDF.
  • Ouvrir la fenêtre d’impression.
  • Exporter le fichier JSON.
Devis verrouillé

Un devis Accepté, Refusé, Expiré ou déjà lié à une facture envoyée ne peut plus être modifié. Utilisez Créer une V2 pour poursuivre sans altérer la trace commerciale.

Contacts

Gérer le répertoire clients

Ouvrez le bouton client du devis pour rechercher, créer ou modifier un contact. Le nom, le téléphone et l’e-mail restent immédiatement accessibles ; ouvrez Plus d’informations pour les autres champs.

Importer

  • CSV avec en-têtes en français ou en anglais.
  • vCard .vcf depuis un carnet d’adresses.
  • JSON BCDevis pour une sauvegarde complète.
  • Les doublons sont fusionnés par e-mail, téléphone, puis nom et adresse.

Exporter

  • CSV pour Excel ou un autre logiciel.
  • vCard pour les téléphones et carnets d’adresses.
  • JSON pour restaurer ou transférer le répertoire.
  • L’export contient tous les contacts du répertoire.
Coordonnées du devis

Quand vous utilisez un contact, BCDevis copie ses coordonnées dans le devis. Les devis déjà enregistrés conservent leur contenu même si le contact change ensuite.

Suivi commercial

Piloter le cycle de vie du devis

Activez le suivi dans Réglages → Devis & suivi, puis ouvrez Mes devis → Suivi. Chaque modification ajoute une ligne datée à la chronologie avec l’auteur et le poste lorsqu’ils sont connus.

Deux vues distinctes

Historique affiche une liste compacte de tous les devis avec leur dernier statut commercial lorsque le suivi est actif. Dans Suivi, survolez une fiche pour afficher son bouton d’ouverture ; sur écran tactile, touchez directement la fiche. Le bouton Ouvrir le devis reste disponible dans le détail.

Relances

  • Une date est proposée lors du passage à Envoyé.
  • Le filtre À relancer regroupe les échéances arrivées.
  • Les rappels au démarrage sont configurables.
  • Une nouvelle date ou une note enrichit la chronologie.

Garde-fous

  • Les rétrogradations sont refusées.
  • Annuler le dernier changement reste disponible avant un état terminal.
  • Les états terminaux verrouillent le devis.
  • Créer une V2 conserve le lien avec la version précédente.
Que fait l’expiration automatique ?

À l’ouverture du suivi, un devis Prêt à envoyer ou Envoyé dont la date de validité est dépassée passe à Expiré. Cette action est ajoutée à sa chronologie.

Factures

Archiver une facture envoyée

BCDevis ne transforme pas automatiquement un devis en facture lorsque son statut change. Il archive le PDF d’une facture déjà créée et envoyée.

  1. 1
    Acceptez le devis

    Le bouton d’import de facture apparaît uniquement sur un devis Accepté.

  2. 2
    Importez la facture envoyée

    Choisissez son PDF. Une connexion à la base centrale est nécessaire pour stocker ce document partagé.

  3. 3
    Retrouvez-la dans Factures

    Après un import réussi, le devis quitte le suivi actif et le PDF rejoint la vue Factures pour consultation, téléchargement et impression.

Nommage cohérent

Le préfixe facture est configurable, FAC par défaut. La date, le code machine et la séquence restent identiques à ceux du devis associé : DEV-20260806A001 devient FAC-20260806A001.

Base centrale

Partager les données entre plusieurs postes

La base centrale est facultative. BCDevis se connecte à une API HTTPS sécurisée, jamais directement à PostgreSQL. Les identifiants de la base ne sont pas enregistrés dans l’application.

Sans base centrale

  • Création et enregistrement des devis.
  • Suivi commercial local.
  • Impression et téléchargement PDF.
  • Aide complète hors ligne.

Avec base centrale

  • Devis et réglages partagés entre postes.
  • Numéros uniques centralisés facultatifs.
  • Bibliothèque de documents et factures PDF.
  • Synchronisation et résolution explicite des conflits.
Pourquoi les boutons Documents et Factures peuvent-ils être absents ?

Ils sont affichés uniquement lorsqu’un poste est connecté à la base centrale. Sans connexion, ils ne promettent pas une bibliothèque indisponible ; les fonctions locales restent actives.

Que se passe-t-il hors connexion ?

Le poste continue avec ses données locales. La synchronisation reprend lorsqu’une connexion valide est retrouvée. En cas de divergence, BCDevis demande quelle version conserver.

Nouvelle adresse

Déplacer BCDevis vers un nouveau domaine

Le stockage d’un navigateur appartient à l’adresse du site. Ouvrir un nouveau domaine ne suffit donc pas pour y retrouver automatiquement les devis de l’ancien.

  1. 1
    Préparez le transfert sur l’ancien site

    Dans Réglages → Données → Changer l’adresse du site, vérifiez la destination puis téléchargez le fichier JSON.

  2. 2
    Ouvrez la nouvelle adresse

    Le bouton devient disponible uniquement après la création d’un fichier à jour. La nouvelle page ouvre directement l’étape d’import.

  3. 3
    Importez et contrôlez

    Sélectionnez le fichier, confirmez le remplacement local, puis vérifiez les devis et les réglages. Si la centralisation était active, reconnectez le poste avec son mot de passe.

Fichier sensible

Le transfert contient les devis, clients et réglages locaux. Il ne contient ni mot de passe ni jeton de session. Gardez-le dans un emplacement sûr, puis supprimez-le après vérification.

PDF

Télécharger, imprimer et joindre un devis

Electron

Dossier configurable

Dans Réglages → Entreprise → Fichiers PDF, choisissez le dossier des devis téléchargés. Ce chemin appartient au poste et n’est pas synchronisé.

PWA / navigateur

Destination contrôlée par le navigateur

Le navigateur applique son propre réglage de téléchargement. BCDevis ne peut pas imposer un chemin local depuis une page web.

  • Télécharger crée le PDF sans changer le statut commercial.
  • Imprimer ouvre la boîte de dialogue du système.
  • E-mail joint automatiquement le PDF dans Electron lorsque le client e-mail le permet.
  • WhatsApp et Outlook Web indiquent quel PDF joindre manuellement.
  • Les fichiers existants ne sont pas écrasés silencieusement.
Imprimer cette aide

Utilisez le bouton Imprimer en haut de page pour obtenir une version papier lisible.
